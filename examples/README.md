# Synthetic examples — never real runtime evidence

The files under `examples/v1/` exercise the neutral envelope schemas only. Their digests, paths, revisions, media sizes and product project IDs are **fabricated test fixtures**. They do NOT imply source media exists, operator permission was granted, a render occurred, a real H3 template was bound, or any product completed cross-repo E2E.

For native exchange, the producer's product-owned adapter must create truthful manifests, and the receiving product must validate both manifest and actual bytes before authorization.
